# Railway Ticket Reservation System (RTRS)

A web-based Railway Ticket Reservation System allowing passengers to search train schedules, check seat availability, book and cancel tickets, make online payments, and view booking history.

## Project Scope (SRS Summary)
- **FR-01**: User Registration
- **FR-02**: User Authentication & Account Lockout (5 failed attempts = 15 min lock)
- **FR-03**: Train Search (Source, Destination, Date)
- **FR-04**: Real-time Seat Availability Display (SL, 3A, 2A, 1A)
- **FR-05**: Ticket Booking & Passenger Details
- **FR-09**: PNR Generation & E-Ticket
- **FR-13 / FR-14**: Ticket Cancellation & Refund Policy

## Authentication Module
- `login.html`: Basic passenger login form skeleton accepting email or phone number and password.
